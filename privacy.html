Sweetfil3d Studio — Privacy Policy

Last updated: 16 October 2026

Sweetfil3d Studio is a private tool used only by the owner of the @sweetfil3d TikTok account, on the owner's own computer.

Data accessed

With the owner's authorization (TikTok Login Kit, scope video.upload), the tool receives an access token for the owner's own TikTok account and uses it only to upload the owner's own videos to the TikTok inbox as drafts.

Storage

The token is stored only on the owner's computer, in a file readable only by the owner. Videos are stored locally. No data is sold, shared with third parties or sent anywhere other than TikTok.

Other users

The tool does not access, collect or store data about any other TikTok user.

Revoking access

Access can be revoked at any time from the TikTok app (Settings and privacy → Security → Apps and services), which invalidates the token.

Contact

Through the @sweetfil3d account on TikTok or Instagram.
